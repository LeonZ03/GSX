# r25：风挡、镜壳、侧盖与后减震重建

**阶段 B、C 仍为 NOT_PASSED。** 本批次从 r20 连续制作、渲染、退回候选并检查至 r25；没有进入贴花、最终材质、4K 或导出。全部建模通过本机 Blender 5.2.2 / Blender MCP 后台完成，没有 Computer Use。版本号不代表阶段通过。

## 保留的几何改动

- **风挡：**保留下部两排安装控制点，调整上缘宽度、曲率和高度。使用固定62/63/69相机及主线程复核的开放可见边缘；镜子挡住的边界不补成真实观测。实际曲面仍为可编辑四边面，三毫米厚度保留。
- **镜壳：**六点扁片改成闭合圆角外壳、内嵌镜片和可编辑镜杆。右侧轮廓参考62/63，左侧使用同类壳体和历史独立调整姿态；69中的较早镜子姿态不能作为同一调节状态。壳深25mm是构造估计。
- **座下黑色侧盖：**重建左右三角 `Body_MidSideCover`。r24曾把重建件与旧件叠放；最终清单检查纠正了“缺失”判断，r25用新件替换旧件并删除重复层。69/70可见边界支持其存在和大轮廓；通过两侧上角投影诊断，使盖板位于外露车架管内侧。尖端初稿加厚自交已修正，未通过移动原车架来掩盖问题。精确深度、支座和隐藏搭接未验收。
- **前链轮外罩：**新增左侧 `Engine_SprocketCover`，可见外表面取自69，分件关系参考官方FIG112A、11360-20K00。深度仍近似；与相邻发电机盖的1mm可编辑避让只是构造间隙，不是实测。隐藏 `Tool_SprocketCoverClearance` 不能删除。
- **后减震：**旧十圈长弹簧改为较短的5.25圈候选，拆分筒体、活塞杆、缓冲块、弹簧座、安装眼、贯穿轴、垫圈及双耳支座。上下眼贯孔和直径10mm销轴真实建网格。两根紧凑横向连接件与当前车架/摇臂相接，撤掉无依据的斜撑。圈数、线径9.2mm、眼位及隐藏连接仍是照片引导的估计；不能作实车悬挂尺寸或运动学结论。

官方参考：[Suzuki车型家族零件目录](https://www1.suzuki.co.jp/motor/support/parts_catalog_manage/files/GSX250RAM1_GSX250RAZM1.pdf)，FIG112A / FIG545A；本地截图在references/raw/stage_bc。目录用于部件拓扑，不当精确尺寸图。

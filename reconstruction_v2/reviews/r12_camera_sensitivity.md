# r12：69号镜头与后座高度敏感性

状态：**M1_NOT_PASSED。证据检查修订r12；模型保持r11，没有新增r12几何文件。**

## 本轮问题与结论

检查r09后座约90 mm的抬高是否主要来自69号照片的相机假设。相机只根据轮圈观测拟合，之后才投影后座；没有让后座误差参与镜头选择。正式相机、19个控制网格和r11源文件均未修改。

25组离散假设产生16组通过轮圈低残差筛查的局部拟合结果。这16组中，旧r08后座在保持自身形状、只允许沿Z平移时，仍需上调约78.5–104.7 mm；r11后座对应的诊断补偿约为−13.0至+15.8 mm。**支持保留此前上调方向，但不足以锁定实物高度。** 没有把这些诊断平移写入模型。

## 方法

- 输入：69号照片68个可见轮圈贴样本；前40、后28，无伪造轴心或遮挡弧线。保持原转向轴、轴距和侧向偏移假设。
- 焦距轮廓：固定10个焦距样本，0.55–5倍图像宽度，其余参数重新拟合。由原候选、按焦距缩放的候选及相邻焦距结果作局部起点；不保证全局最优。部分高焦距结果存在局部极小值问题，不能据此排除整个焦距范围。
- 圈贴半径：原220 mm，以及既有不确定范围内的215/225 mm。
- 主点：相对图像中心，水平或垂直各偏移±3%图像尺寸；这是本轮选定的测试幅度，没有EXIF或标定证明它包住真实值。另测半径与主点组合的8个角点。
- 保留原转向软先验，使用soft_l1优化。另行报告纯轮圈像素残差，不把先验项混入像素RMS。冻结镜头的纯轮圈RMS约0.383 px；旧0.395包含先验，二者不是改前/改后进步。
- 低残差筛查：RMS≤1 px、P95≤2 px、优化成功、位姿方向合理、优化参数不贴边。它只是挑选可比较的诊断样本，**不等于相机通过或统计置信区间**。
- 后座投影来自Blender MCP后台读取的r11实际求值网格，以及已有r08求值网格。使用原69人工闭合边界（约±4 px），独立分件轮廓双向最近距离；不包含相邻部件遮挡，不是同名关键点误差。
- 每个镜头下，对两版后座分别扫描Z偏移，再局部细化。该“高度补偿”受固定形状和标注影响，不能当作真实后座坐标测量。

## 可复算结果

| 检查项 | 本次离散样本结果 |
|---|---|
| 低残差诊断候选 | 16 / 25 |
| 同一r11后座网格质心的投影跨度 | 水平24.5 px、垂直15.8 px |
| 旧r08仅Z平移的诊断补偿 | +78.5 至 +104.7 mm |
| 当前r11仅Z平移的诊断补偿 | −13.0 至 +15.8 mm |
| 固定r11后座的平均边界距离 | 4.49–8.04 px |
| 冻结原镜头下，r08 / r11平均距离 | 29.14 / 4.60 px |

同一几何体在这些镜头下仍会移动十几个至二十几个像素。低轮圈残差不能消除车身投影不确定性；以上范围不是连续参数空间的保证，更不是整车毫米精度。r08和r11还存在宽度、长度、圆角差异，因此两个版本的Z补偿也不能解释成唯一真实高度差。

## 局限与下一步

尚未扰动镜头畸变、圈贴侧向平面位置、25.6°/104 mm车型家族先验，也没有把提取误差相关性、±4 px人工标注不确定性转换成统计区间。本轮仍使用参与形体调整的69，**没有增加独立验收角度**。70继续标定失败，不能当作有效相机。

下一步先对座尾与油箱—座垫接口补充可复核的可见边界和稳定特征，优先跨62/63及69比较；要缩小后座高度不确定性，仍需轮圈以外的独立尺寸/结构证据，必要时继续单列标定修订。61仍保留，不能随意用于形体拟合后再称holdout。形体与镜头不同时优化；暂不制作贴花、材质或4K。
